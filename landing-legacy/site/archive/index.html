Council Mode · BlockerBanner + ObserverPanel

Два ИИ. Один ловит то,
что другой пропустил.

Главная киллер-фича Aura. Оркестратор делает работу, наблюдатель просыпается на каждом чекпойнте, читает только изменённую поверхность и пушит обоснованные находки обратно — как баннер в чате, который нельзя пропустить.

Слева — основной чат
Оркестратор
Claude Code или Codex выполняет вашу задачу. Пишет чекпойнты в .council/checkpoints/
↔
Справа — панель наблюдателя
Наблюдатель
Читает delta, возвращает обоснованные STOP / WARN / NOTE / INFO. Привязан к изменённой поверхности — никаких галлюцинаций.
STOP Обнаружена уязвимость в обработке токенов — рекомендую остановить деплой до фикса

Парные сессии в один клик

  • claude + claude default — две сессии Claude Code в одной рабочей области
  • claude + codex experimental — оркестратор на Claude, наблюдатель на Codex для кросс-модельной независимости
  • Включается переключателем в диалоге New Session

UI-компоненты в браузере

  • BlockerBanner — последний STOP в слоте чата, JSX-escaped, дисмиссится
  • ObserverPanel — статус-пилюля sleeping / spawning / reviewing / blocker-found + сворачиваемый лог
  • ProviderBadges — асимметричные чипы при mixed-provider парах
  • Хоткеи ⌘⇧O и ⌘⇧B

Вопросы

Что обычно спрашивают

Нужен ли VPN для работы?
Нет. Сайт работает напрямую из России, Беларуси, Казахстана и других стран СНГ. Мы держим инфраструктуру так, чтобы доступ был стабильным без обходных путей.
Как платить из РФ?
Картой МИР, через СБП, ЮKassa, CloudPayments, по криптокошельку. Не нужна иностранная карта или счёт.
Это правда программирует «домохозяйка»?
Да. Голосом по-русски вы описываете задачу — например, «сделай мне систему учёта расходов». Aura уточнит детали и соберёт работающее решение. Вам не нужно знать код.
Чем это отличается от ChatGPT?
Aura — это не один диалог, а целая платформа: 29 инженерных навыков, Council Mode для проверки качества, самообучающаяся база знаний. И всё это доступно из СНГ без VPN.
Что такое MetaPersonaGPT?
Это флагманский советник проекта Razumai.space — отдельной платформы, построенной на Aura Companion. Из одной беседы он типирует вас по 27+ психологическим системам. Aura это инструмент-основа, Razumai это пример того, что на ней можно создать.
А если я разработчик и хочу свой инстанс?
Берите код по MIT-лицензии на GitHub. Или оформите Vibecoder API и получите токен auraco, который подключается к нашей инфраструктуре. Claude может настроить локально за вас, если дать ему ссылку на репозиторий.
Безопасны ли мои данные?
Сессии хранятся зашифрованными. Голосовые данные не используются для обучения. Можно удалить историю в один клик. Self-hosted версия — полный контроль над данными.
