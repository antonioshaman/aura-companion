The honest answer to the obvious question

Why, if you already have Claude Code and Codex?

Short version: Aura doesn't replace them and doesn't make the model smarter. It removes the friction around the agent — usage limits, hangs, restarts, being away from your laptop — and adds a second opinion from a different model.

Aura doesn't replace them

  • It runs the official claude / codex CLI unchanged: your CLAUDE.md, skills, MCP servers and chosen model work exactly as they do now.
  • No hidden prompts injected by default — the knowledge base loads only when you ask for it.
  • It doesn't rewrite the start of your prompt: our prompt-cache audit shows a 97.5% cache hit rate.
  • Close the tab and it's the same Claude you have in the terminal. No lock-in: uninstall Aura and your Claude Code setup is untouched.

What Aura does not do

  • It doesn't make the model smarter. Same Claude, same Codex.
  • It doesn't come with a subscription — it runs on your own Claude or Codex plan.
  • It's not a magic button. It's an interface and a safety net around the agent, not a new agent.

Questions

What people usually ask

Why add a layer on top, when I can just use Claude Code and Codex?
If the terminal is enough for you, keep using the terminal — that's the honest answer. Aura helps when the friction around the agent gets in the way: work stalls on a usage limit overnight, a reply is lost when something hangs, the server restarts, you're away from your laptop, or you want a second model to check the code. Underneath it's the same official CLI. Three concrete jobs →
Wrappers and personal frameworks make agents worse. Isn't Aura the same?
A fair worry — plenty of wrappers rewrite the system prompt and break the model's behaviour. Aura runs the official claude and codex unchanged: your CLAUDE.md, skills, MCP servers and model stay as they are. There are no hidden prompts by default — the knowledge base loads only on request. Our prompt-cache audit shows a 97.5% cache hit rate, meaning we don't touch the start of your prompt. Anthropic's and OpenAI's own best practices apply exactly as in the terminal.
This sounds too good. What's the catch? Do I need to sign up?
There's no sign-up. To run it yourself: bunx aura-companion → localhost:3456; it uses your own Claude or Codex subscription and is removed with one command. No catch, but no miracles either: Aura doesn't make the model smarter and doesn't include a subscription. It resumes work after a limit, gets a second opinion from another model, and keeps your work across restarts. All the code is open under MIT — check it yourself.
Isn't it easier to tune Claude to my own taste?
Maybe — if you have the time. Aura is roughly what you'd have after three months: we've already hit the lost replies, hangs, usage limits and restarts. It's MIT, so you can lift just the methodology (skills, Council Mode, knowledge base) into your own setup, or take the whole thing.
I'm in Russia or the CIS. Do I need a VPN?
No. The site works directly from Russia, Belarus, Kazakhstan and other CIS countries. We run the infrastructure so access stays stable without workarounds.
How much does it cost?
Nothing. It's a non-profit project — no plans, no subscriptions. All the code is open under MIT; take it and use it. You still need your own Claude or Codex plan for the models themselves. If you'd like to support development, there are donation options below — entirely optional.
Can someone who doesn't code really use it?
Yes. You describe the task in plain words — say, "build me an expense tracker". Aura asks for the details and assembles a working solution. You don't need to know how to code.
How is this different from ChatGPT?
Aura isn't a single chat but a working environment for coding agents: 29 engineering skills, Council Mode for quality checks, and a self-learning knowledge base — on top of the real Claude Code and Codex.
What is MetaPersonaGPT?
The flagship advisor of Razumai.space — a separate, Russian-language platform built on Aura Companion. From one conversation it types you across 27+ psychological systems. Aura is the foundation; Razumai is an example of what you can build on it.
I'm a developer — can I run my own instance?
Yes. Take the code from GitHub under MIT and run your own instance, with no fees or limits. Claude can set it all up locally for you if you give it the repo link.
Is my data safe?
Sessions are stored encrypted. Voice data isn't used for training. You can delete your history in one click. The self-hosted version gives you full control over your data.
