Честно о главном вопросе

Зачем, если есть Claude Code и Codex?

Коротко: Aura их не заменяет и не делает модель умнее. Она убирает трение вокруг агента — лимиты, зависания, рестарты, работу с телефона — и добавляет второе мнение от другой модели.

Aura их не заменяет

  • Запускает официальный CLI claude / codex без изменений: ваши CLAUDE.md, навыки, MCP и выбранная модель работают как есть.
  • По умолчанию не подмешивает скрытых промптов — база знаний подключается только по запросу.
  • Не переписывает начало промпта: аудит prompt-cache — 97,5% попаданий в кэш.
  • Закрыли вкладку — это тот же Claude, что в терминале. Без привязки: удалите Aura, и ваш Claude Code останется как был.

Чего Aura не делает

  • Не делает модель умнее. Тот же Claude, тот же Codex.
  • Не даёт подписку — работает на вашей подписке Claude или Codex.
  • Не волшебная кнопка. Это интерфейс и страховка вокруг агента, а не новый агент.

Три конкретные задачи

01
В голом терминалеНочью упёрлись в 5-часовой лимит — агент стоит до утра, пока вы не напишете «продолжай».
С AuraСама продолжает работу примерно через 1–2 минуты после сброса лимита.
Реальный лог прода, 16.10.2026: лимит в 20:57, авто-продолжение в 22:01 — без участия человека.
02
В голом терминалеАгент уверенно пишет баг — и сам же его не замечает. Ловить его будете вы.
С AuraВторая модель проверяет каждый шаг (Council Mode): Codex ревьюит Claude и наоборот.
За один день на нашем собственном коде две разные модели нашли 12 реальных багов, включая путь утечки токена. И нашли разные баги.
03
В голом терминалеНесколько проектов в разных окнах терминала; рестарт сервера или зависание — и ответ потерян; отошли от ноутбука — работа встала.
С AuraВсе сессии в одном окне, в том числе с телефона. После рестарта сервера сессии поднимаются сами, ответы больше не теряются при зависаниях.
Как это устроено — открыто: session-lifecycle.md на GitHub →
Скоро
Видео «3 задачи под кофе», 2–3 минуты. Ещё не снято — честно. Покажем ровно три сценария выше, на живом проекте:
  1. лимит ночью → утром работа уже продолжена;
  2. Codex ловит баг Claude до коммита;
  3. рестарт сервера → сессии на месте, всё видно с телефона.

Council Mode · BlockerBanner + ObserverPanel

Два ИИ. Один ловит то,
что другой пропустил.

Главная киллер-фича Aura. Оркестратор делает работу, наблюдатель просыпается на каждом чекпойнте, читает только изменённую поверхность и пушит обоснованные находки обратно — как баннер в чате, который нельзя пропустить.

Слева — основной чат
Оркестратор
Claude Code или Codex выполняет вашу задачу. Пишет чекпойнты в .council/checkpoints/
↔
Справа — панель наблюдателя
Наблюдатель
Читает delta, возвращает обоснованные STOP / WARN / NOTE / INFO. Привязан к изменённой поверхности — никаких галлюцинаций.
STOP Обнаружена уязвимость в обработке токенов — рекомендую остановить деплой до фикса

Парные сессии в один клик

  • claude + claude default — две сессии Claude Code в одной рабочей области
  • claude + codex experimental — оркестратор на Claude, наблюдатель на Codex для кросс-модельной независимости
  • Включается переключателем в диалоге New Session

UI-компоненты в браузере

  • BlockerBanner — последний STOP в слоте чата, JSX-escaped, дисмиссится
  • ObserverPanel — статус-пилюля sleeping / spawning / reviewing / blocker-found + сворачиваемый лог
  • ProviderBadges — асимметричные чипы при mixed-provider парах
  • Хоткеи ⌘⇧O и ⌘⇧B
