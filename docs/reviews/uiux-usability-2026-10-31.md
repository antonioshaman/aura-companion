Согласованный scope: [план](../../PLAN-aura-uiux-usability-followup.md); девять независимых экспертных отчётов — `.council/plan-output/2026-10-31-uiux-usability/`. Исправления выполнены ИИ; человеческого code review ещё не было.

## Короткий лист приёмки

| Исправлено | Как проверено |
|---|---|
| Черновики и изображения разделены по сессиям; форма Home помнит проект при обычных переходах | Claude/Codex: A→B→A, remount, вложения; Home→Settings→Home в браузере |
| Оба редактора сохраняют несохранённые изменения при поздних ответах и сбое дерева | Deferred load/save/refresh regression tests; render + axe + взаимодействия |
| Agents/Runs отличают ошибку от пустого списка; старый запрос не подменяет новый фильтр | Ошибка→Retry, последние данные, перекрывающиеся poll/filter запросы |
| Режимы имеют понятные подписи; во время reconnect можно писать | Оба backend, все известные/неизвестный/отсутствующий режимы; без изменения прав CLI; отправка без связи запрещена |
| Выбор папки возвращает фокус; Council-компоненты имеют уникальные связи и корректные подписи | Escape/Close/выбор/backdrop; два экземпляра; компонентные axe scans |
| PWA не перезагружает вкладку сама; Update загружает новую сборку даже в первой вкладке | Две разные Vite-сборки A/B: до Update тот же документ и текст, после — B; отдельный cross-tab unit test |
| Codex принимает новое служебное уведомление CLI и не срывает первый ответ | Реальный smoke воспроизвёл отказ; captured replay + схема установленного Codex 0.162.1; проверка ответа после выкладки |
| KB сохраняет разные версии одного ID; повреждённый отчёт и начавшийся анализ безопасно отклоняются | Временные файлы, отдельный процесс-писатель, вложенный malformed JSON, streaming request |

**Ограничение KB:** разрушительные Archive и prune временно недоступны до общего протокола записи с внешним `/learn`. Анализ, Keep, отметка на объединение и `prune --dry-run` работают. Незавершённый Archive сохраняет свой sentinel и не повторяет разрушительную операцию при запуске.

**Черновики:** сохраняются при переходах внутри открытой вкладки; перезагрузка/закрытие вкладки их не сохраняет. Перед Update интерфейс предлагает скопировать несохранённый текст.

## Подтверждённые находки

Шкала 0–4; heuristic по Nielsen. Неподтверждённые device-гипотезы не выданы за дефекты.

| Экран / сценарий | Severity / heuristic | Доказательство → минимальное исправление |
|---|---|---|
| KB: старый Archive и новая строка с тем же ID | 3 / предотвращение ошибок | Red test: новая версия исчезала → сравнение полного содержимого, сохранение обеих версий |
| KB: внешний писатель после последнего stat | 3 / предотвращение ошибок | Отдельный процесс в temp-dir доказывает потерю append → destructive callers fail-closed; stat не назван CAS |
| Diagnostics: вложенный повреждённый report | 3 / восстановление после ошибок | `[null]`, missing entry, malformed memory давали throw/available → total boundary validator |
| Diagnostics: анализ стартовал во время чтения тела решения | 2 / предотвращение ошибок | Streaming request получал 200 → повторная проверка перед применением, 409 без записи |
| Composer: A→B и уход с черновиком | 3 / контроль пользователя | Red tests для обоих CLI → отдельный transient owner каждого draft |
| Home: обычная навигация | 2 / контроль пользователя | Ввод/проект/вложения принадлежали mount → отдельный Home draft; явный «+» очищает его |
| CLAUDE.md / файловый редактор: поздние ответы | 3 / предотвращение ошибок | Три red tests → привязка load/save к контексту/ревизии, ошибка дерева сохраняет файл |
| Agents/Runs: network failure, поздний фильтр/poll | 2 / видимость состояния | Ошибка выглядела пустотой, поздний All заменял Error → error/stale/Retry, latest request owns result |
| Composer: raw acceptEdits, reconnect input disabled | 2 / соответствие языку пользователя | Table tests → display-only подписи, локальный ввод при запрете отправки |
| FolderPicker: Escape/выбор | 2 / контроль пользователя | Реальный DOM: фокус уходил в BODY → общий modal focus contract |
| Повторные Council-компоненты / поясняющие chips | 1 / последовательность | Четыре red tests с duplicate IDs, DOM incomplete → useId, group/note семантика |
| Codex: первый ответ новой сессии | 3 / восстановление после ошибок | Реальный SSE/WS: turn/moderationMetadata ошибочно принят за drift → известный метод с проверкой envelope, metadata opaque по CLI schema |
| PWA: Update в первой вкладке | 2 / видимость состояния | Реальные A/B: worker B активен, документ A не сменился → native registration с явным согласием этой вкладки |

## Границы проверки

Сохранённые доказательства: [матрица браузера](assets/uiux-browser-matrix-2026-10-31.json), [навигация и фокус](assets/uiux-navigation-2026-10-31.json), [две PWA-сборки](assets/uiux-pwa-proof-2026-10-31.json), [скриншот](assets/uiux-pwa-waits-for-update.png). Это Chromium и read-only зеркало API, а не физический Safari. `axe incomplete` для закрытых условных listbox-controls остаётся ручной проверкой, не PASS. Нулевые violations не означают полной доступности.

Владельцу на iPhone осталось:

1. Несколько раз «+» → новая сессия; возврат из фона — без самопроизвольного перехода Home→Session.
2. Текст + картинка: A→B→A и Settings→назад; выбранный проект остаётся своим.
3. Редактор: ввод во время Save, обновление дерева, клавиатура и прокрутка.
4. VoiceOver: выбор папки, Escape/закрытие и возврат фокуса; PWA Update после копирования черновика.

Реальное создание и подключение Claude прошли; ответ заблокирован требованием верификации аккаунта Anthropic. Codex smoke выявил и закрыл протокольную несовместимость; окончательный ответ проверяется после выкладки. Это отдельные свидетельства от UI-моков. Статус доставки и окончательные числа проверок — в [журнале реализации](uiux-implementation-2026-10-31.md).
