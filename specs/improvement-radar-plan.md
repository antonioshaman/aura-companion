# Council Plan (Aura): Радар улучшений и актуальность моделей

**Статус:** план, код приложения не изменён. Границы подтверждены пользователем 26 ноября 2026.
**Объём:** автоматический поиск новинок GitHub и моделей, оценка применимости к Aura, короткий список предложений. Никакого автоматического внедрения.
**Пользователи:** владелец установки Aura, включая несколько вкладок; сервер, интерфейс и локальное хранение.
**Вне объёма:** установка CLI и зависимостей, изменение кода, создание PR, запуск реализации, смена выбранной модели, новые inference-провайдеры. Бюджеты сессий, watchdog и прочие пункты прежнего списка — отдельные фичи.

## Что уже есть

- `web/server/routes.ts`: список Codex из локального каталога CLI; Claude — через `anthropic-models-cache.ts`. `model-registry.ts` только аннотирует известные модели, не добавляет новые.
- `web/server/routes/settings-routes.ts`, `web/src/components/SettingsPage.tsx`: диагностика каталогов и ручное обновление уже реализованы. Для Codex обновление сейчас означает только проверку наличия кеша; это не свидетельство свежести.
- `web/server/diagnostics/kb-analysis-runner.ts`: подходящий пример ограниченного запуска с одним владельцем состояния. `CronScheduler` запускает полноценные CLI-сессии и не подходит Радару по умолчанию.
- На обследованном окружении: CLI `0.162.1`, каталог от 28 октября, GPT-6.2 отсутствует. Это локальное наблюдение, не доказательство ограничений аккаунта или состояния другой установки.

**Принятое решение:** первая версия полезна без LLM: конкретные правила сопоставляют новости с проверяемым перечнем возможностей Aura и формируют короткие предложения. Неподтверждённое соответствие явно помечается. Новая система LLM-оценки в первую версию не входит; она потребовала бы отдельного доказательства изоляции для обоих CLI.

Задать ограниченные темы поиска и список проверяемых возможностей Aura с локальными ссылками-основаниями; пользовательские URL и свободные команды не становятся источниками выполнения.

## Риски и границы

- **Hunt:** «только рекомендации» обеспечивается отсутствием исполнительных возможностей, а не инструкцией в промпте. Пересылка приватного кода, истории сессий и секретов во внешние источники не разрешена.
- **Willison:** источник недоступен — причина неизвестна, а не «модель недоступна вашему тарифу». Данные разных CLI homes/аккаунтов нельзя смешивать; использовать контекст реально запускаемого backend.
- **Fowler:** изменения не требуют нового универсального планировщика, плагинной платформы или расширения `ws-bridge.ts`. Не менять существующую форму массива моделей ради метаданных свежести.
- **Beck:** проверки не используют настоящий домашний каталог машины; фиксируют пользовательские результаты и отсутствие побочных эффектов.
- Уже реализованные возможности требуют поддерживаемого перечня оснований. Автоматическое чтение всего репозитория и «знающая всё» LLM не входят в первую версию.

**Предлагаемые начальные ограничения, не отдельные решения пользователя:** ручная проверка доступна сразу; расписание включается явно, раз в сутки; до 20 источников/поисковых тем, 100 находок и 10 видимых предложений за проход; дедлайн 60 секунд, пауза ручных повторов 60 секунд; признак устаревшего каталога — старше 24 часов. Эти значения должны быть настройками/проверяемыми политиками, а не обещанием полноты поиска. Если официальный источник нельзя надёжно обработать в лимитах, показывать это ограничение, не обходить его свободным браузингом.

## Council и происхождение

Dispatching 4 advisors because the new persisted radar touches security, structure, recommendation quality and behavioral tests; economy policy drops specialists while retaining all four guaranteed cross-stack lenses. Оценка объёма для triage: около 18 файлов / 1400 строк, не обязательство реализации. Риск хранения делает Council обязательным; решение economy записано через `council-triage.ts`.

Fowler, Hunt, Willison и Beck — независимые AI-агенты; человеческого ревью не было. Каждый защищает AC, указанные в задачах. Подробные ответы и вычисленный состав: `.council/plan-output/20261126T200528Z-improvement-radar/`.

  - <workspace>/AGENTS.md (symlink)

   2. beck        ● test-quality  ← cross-stack lens

AGENTS.md — известная ссылка на CLAUDE.md, инструкции доступны в контексте. Полный состав валиден по `validateChosenRoster`; подтверждение запуска получено до dispatch. Движок исключил `dahl`, `abramov`, `friedman`, `ritchie`, `durov`, `vanrossum` по `over-budget`, `hashimoto`, `saarinen`, `brandur` по `no-domain-match`. Применимые вопросы протокола, UI, хранения и a11y закреплены за AC и проверками, новые CLI-протоколы в объём не входят.

**Отклонение от skill:** в выбранном каталоге у Beck отсутствует `plan-aura.md`; задание составлено председателем по существующему `quality-testing.md`, режим specify. Это явно не запуск отсутствующего шаблона; остальные три эксперта получили каталожные роли с разрешёнными абсолютными путями справочников. TodoWrite в текущем наборе инструментов отсутствует.

## Вердикт

Начать с контракта и доказательств применимости. Радар должен выдавать мало полезных предложений, сохранять решения пользователя и честно показывать пробелы данных; каталог моделей остаётся под управлением существующих источников. Реализация и установка обновлений этим планом не выполняются.
