# Обновление доступных моделей

Небольшое расширение существующего каталога. Пользователь хочет получать актуальные доступные модели из интерфейса или автоматически, без запуска полноценной агентной задачи.

## Приёмка
- Кнопка обновления обращается к установленному Codex CLI за каталогом аккаунта; Claude сохраняет обновление через настроенный Anthropic API-ключ.
- При открытии новой сессии устаревший/отсутствующий каталог обновляется автоматически. Свежие результаты кешируются на час, параллельные запросы объединяются; ошибки не вызывают бесконечных попыток.
- При недоступности провайдера/CLI остаётся прежний список и выводится честный результат ошибки. Анонсы не создают недоступные аккаунту модели.
- Обновление не запускает thread/turn, не меняет выбранную пользователем модель и не устанавливает CLI.
- Кнопка и подсказки одинаково доступны для Claude/Codex; отсутствие Anthropic API-ключа объясняется отдельно от подписки Claude Code.

## Границы
Автоматизируется получение каталога при открытии формы новой сессии. Установка CLI, смена учётной записи, платные inference-вызовы и автоматический выбор модели не входят в изменение. Имеющиеся CLI/auth/cache остаются источником истины. Проверки: записанный CLI roundtrip, ограничения процесса/протокола, single-flight/cooldown, route/auth, render/axe/interactions и сохранение выбора.

## Выполнено
Короткоживущий stdio app-server выполняет только initialize/initialized/model/list и завершает собственный процесс с TERM→KILL, ожидая reap. Ограничения:15s+1s на остановку,1MB протокольного вывода,2MB кеша. Общий CODEX_HOME соответствует существующему глобальному каталогу; credentials не копируются, установка CLI и thread/turn не вызываются. Результат ok требует свежего CLI-owned кеша, а не только ответа встроенного списка.

Обнаружено и воспроизведено дополнительное remoteControl/status/changed между initialize и model/list: добавлена записанная фикстура с редактированными host/installation/timestamp и red→green проверка. Неизвестные методы/невалидные ответы по-прежнему отклоняются.15 новых тестов покрывают протокол, replay, ограничения, ошибки, single-flight/cooldown/cache.501 интеграционный тест прошёл до финального replay-дополнения; дополнительный тест сохраняет ручной выбор модели после замены каталога.

Проверенный факт: живой вызов новой реализации вернул ok, обновив каталог аккаунта. На проверенной установке CLI0.162.1 возвращает6.1-варианты;6.2 не добавляется искусственно.
